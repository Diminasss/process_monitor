Цель:
Научиться использовать базовые утилиты Linux (ps, awk, sed, head, tail, cat и др.), а также читать информацию о процессах через /proc. Получить навыки
построения мониторинговых Bash-скриптов.
Задание:
Написать Bash-скрипт, который:
1. С помощью команды ps aux находит процесс с наибольшей загрузкой CPU.
2. Извлекает PID этого процесса.
3. Используя PID, получает информацию о процессе из /proc/PID:
4. Выводит всю информацию в читаемом виде (формат произвольный)

Дополнительно (по желанию):
1. Получите информацию из других источников (оценивается дополнительно)

Цикличность:
1. Скрипт должен работать в бесконечном цикле с паузой 5 секунд между итерациями. 
2. На каждой итерации — очищать экран (clear) и выводить актуальные данные о текущем лидере по CPU.

Ограничения:
1. Не использовать утилиты вроде top, htop, atop, pidstat, pgrep и ps -eo — только ps aux, пайпы и команды обработки текста.
2. Вся логика должна быть реализована в одном bash-скрипте.
